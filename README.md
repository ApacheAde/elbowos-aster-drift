# Aster Drift

Full-colour Python 3 neon asteroid blast arcade for ElbowOS.

Steer a cyan ship. Blast falling neon asteroids. Larger rocks split. Keep the score climbing.

A / D or ← → move. Space / ↑ fire. R restart.

## Play

```bash
pip install -r requirements.txt
python3 aster_drift.py --play
```

## Record a 9:16 reel

```bash
python3 aster_drift.py --record
```

Outputs `ASTER_DRIFT_ElbowOS.mp4` (1080x1920, ~15s, 30fps).
